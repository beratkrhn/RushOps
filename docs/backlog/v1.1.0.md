# Backlog v1.1.0 – Waffensystem

**Ziel:** Zur Startwaffe kommen Sturmgewehr, Schrotflinte und Dual-Pistolen. Man schaltet sie über Bosssiege frei, wählt eine vor dem Level und kann im Level eine zweite von der Wand nehmen.

**Fertig, wenn:** Auf dem iPhone jede Waffe vor einem Level gewählt, im Level eine Wandwaffe aufgehoben und per Tausch-Button gewechselt werden kann, und alle Bosse mit jeder Waffe etwa in der geplanten Zeit fallen.

**Voraussetzung:** v1.0.0 ist veröffentlicht (W1).

**Grundlage:** Epic #171, Entscheidungen W1 bis W10 in [`design-fragen.md`](design-fragen.md#waffen), Lastenheft F-SPF-05 und Abschnitt 8. Kurzfassung:
- Drei neue Waffen (W2): Sturmgewehr (schneller, etwas Streuung), Schrotflinte (langsam, 5 Kugeln im Fächer, kurze Reichweite), Dual-Pistolen (abwechselnd links und rechts, sehr schnell, wenig Schaden).
- Unterschiede nur in Feuerrate, Schaden, Streuung, Kugeln pro Schuss, Reichweite und Klang; kein Nachladen, keine Munition (W3).
- Alle Waffen haben etwa denselben Schaden pro Sekunde wie die Startwaffe; Bosse und Sterne werden nicht pro Waffe abgestimmt (W7).
- Je eine Waffe pro Bosssieg (W4), Auswahl vor dem Level im Menü (W5).
- Im Level hängen Waffen als Silhouette an festen Stellen an der Wand. Etwa 0,5 s davor stehen hebt sie auf, kostenlos, bis Levelende, auch wenn sie noch gesperrt ist (W6, W8).
- Zwei Slots: gewählte Waffe und eine aufgehobene; eine neue Wandwaffe ersetzt den zweiten Slot. Ein kleiner Tausch-Button neben dem Dash erscheint mit zwei Waffen (W9, W10).

## 1. Waffen-Grundlage: Waffendaten und zwei Slots (#173)

**Story:** Als Spieler möchte ich mehrere Waffen haben können, die sich unterschiedlich anfühlen.

**Akzeptanzkriterien**
- [ ] `WeaponDefinition` (ScriptableObject) je Waffe: Name, Feuerrate, Schaden, Streuung, Kugeln pro Schuss, Reichweite, Schussgeräusch, Icon (W3); die Startwaffe wird zur ersten Definition, ihr Spielgefühl bleibt gleich
- [ ] Kein Nachladen, keine Munition; Auto-Feuer wie bisher (F-STE-02)
- [ ] Zwei Slots als reine Logik (`WeaponSlots`): gewählte Waffe und eine aufgehobene; eine neue Waffe ersetzt den zweiten Slot, Tauschen wechselt die aktive (W9)
- [ ] Perks Doppelschaden und Insta-Kill wirken auf jede Waffe; die Zielhilfe nutzt die Reichweite der aktiven Waffe
- [ ] EditMode-Tests für Slots, Streuung, mehrere Kugeln pro Schuss und Reichweite
- [ ] Hilfsfunktion für Schaden pro Sekunde; Test, dass alle Waffen-Assets innerhalb von ±15 % der Startwaffe liegen (W7)

**Anforderungen:** F-SPF-05, F-STE-02, Lastenheft Abschnitt 8, Entscheidungen W1 bis W10

## 2. Drei neue Waffen: Werte, Schüsse, Klang (#174)

**Story:** Als Spieler möchte ich Sturmgewehr, Schrotflinte und Dual-Pistolen ausprobieren können.

**Akzeptanzkriterien**
- [ ] Sturmgewehr: schneller als die Startwaffe, etwas Streuung (W2)
- [ ] Schrotflinte: langsam, 5 Kugeln im Fächer, kurze Reichweite (W2)
- [ ] Dual-Pistolen: sehr schnell, wenig Schaden, Schüsse abwechselnd links und rechts (W2)
- [ ] Alle mit etwa demselben Schaden pro Sekunde wie die Startwaffe (W7); Werte in den Assets
- [ ] Eigenes Schussgeräusch je Waffe per Skript in `Tools/` (8-Bit, G9, G10); eigener Kugel-Look und Icon je Waffe per `Tools/gen_pixelart.py`
- [ ] In der Testarena per Debug-Menü umschaltbar, um das Spielgefühl am Gerät abzunehmen

**Anforderungen:** F-SPF-05, Lastenheft Abschnitt 8, Entscheidungen W1 bis W10

## 3. Wandwaffen und Tausch-Button (#175)

**Story:** Als Spieler möchte ich im Level Waffen von der Wand nehmen und zwischen zwei Waffen wechseln.

**Akzeptanzkriterien**
- [ ] Wandwaffe: Silhouette der Waffe an einer Wand (eigenes Sprite je Waffe); etwa 0,5 s davor stehen, ein Ring füllt sich, dann ist sie aufgehoben; kostenlos (W8). Werte in einem ScriptableObject
- [ ] Die Waffe bleibt bis Levelende, auch wenn sie noch nicht freigeschaltet ist (W6, W8); sie kommt in den zweiten Slot und ersetzt eine dort liegende (W9)
- [ ] Die Silhouette bleibt hängen; mit der Waffe in der Hand passiert dort nichts
- [ ] Tausch-Button neben dem Dash, erscheint erst mit zwei Waffen; zeigt das Icon der anderen Waffe (W10)
- [ ] HUD zeigt das Icon der aktiven Waffe
- [ ] Wandwaffen im `LevelBlueprint` als Position plus Waffe beschreibbar; der Validator prüft, dass sie an einer Wand hängen und für einen 2×2-Körper erreichbar sind
- [ ] EditMode-Tests für das Aufheben (Zeit, Abbruch beim Weggehen); PlayMode-Test: aufheben, tauschen, schießen

**Anforderungen:** F-SPF-05, F-HUD-*, docs/level-design.md, Entscheidungen W1 bis W10

## 4. Waffen freischalten und vor dem Level wählen (#176)

**Story:** Als Spieler möchte ich nach einem Bosssieg eine neue Waffe bekommen und sie vor dem Level auswählen.

**Akzeptanzkriterien**
- [ ] Je eine Waffe durch einen Bosssieg (W4); Vorschlag: Koloss → Schrotflinte, Brutmutter → Sturmgewehr, Mega-Boomer → Dual-Pistolen; Zuordnung in den Daten, nicht im Code
- [ ] Freischaltungen und gewählte Waffe im Savegame, mit Migration (ADR 0005)
- [ ] Waffenauswahl im Menü ähnlich dem Skin-Karussell; gesperrte Waffen zeigen ihre Bedingung („Besiege den Koloss“) (W5)
- [ ] Die gewählte Waffe liegt beim Levelstart im ersten Slot
- [ ] Ergebnisbildschirm nach dem Bosssieg meldet die neue Waffe
- [ ] EditMode-Tests für Freischaltung und Migration; PlayMode-Test: Auswahl wird gespeichert und im Level benutzt

**Anforderungen:** F-SPF-05, ADR 0005, Entscheidungen W1 bis W10

---

## 5. Wandwaffen in den Leveln platzieren (#177)

**Story:** Als Spieler möchte ich in den Leveln Waffen finden, die sich lohnen.

**Akzeptanzkriterien**
- [ ] Jedes reguläre Level hat ein bis zwei Wandwaffen an festen Stellen, bevorzugt als Belohnung in seitlichen Abzweigungen oder nach einem Rätsel (Fundort: feste Stellen)
- [ ] Boss-Level haben eine Wandwaffe in der Zone vor der Arena
- [ ] Verteilung: jede neue Waffe ist auf ihrer Insel mindestens einmal zu finden, bevor man sie freischaltet
- [ ] Validator und Erreichbarkeits-Tests bleiben grün
- [ ] Sterne-Schwellen prüfen; nach dem Spieltest angepasst

**Anforderungen:** F-LVL-01 bis F-LVL-06, docs/level-design.md, Entscheidungen W1 bis W10
